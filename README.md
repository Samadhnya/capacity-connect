## Overview

CAPACITY CONNECT is a centralized digital capacity-building and learning management platform designed to connect **Trainees, Trainers, and Administrators** through a unified learning ecosystem.

The platform enables organizations to manage training programs, courses, learning resources, assessments, trainee performance, certifications, feedback, competency mapping, and administrative activities through a single secure and scalable system.

---

## Key Features

### Trainee Management

* Professional profile with qualifications, experience, skills, and interests
* Course discovery and enrollment
* Access to learning materials and recorded lectures
* Subject-wise MCQ assessments
* Progress and performance tracking
* Digital certificate management
* Course feedback and notifications

### Trainer Management

* Professional trainer profile and expertise
* Course and module management
* Upload and management of learning resources
* MCQ questionnaire and assessment creation
* Assessment deadlines and monitoring
* Trainee participation and performance tracking
* Trainer resource library

### Administration

* User approval and role management
* Course and enrollment monitoring
* Assessment and certification management
* Participation and performance analytics
* Competency mapping
* Notifications and announcements
* Centralized administrative dashboard

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/capacity-connect.git
cd capacity-connect
```

Install dependencies:

```bash
npm install
```

Create a `.env` file:

```env
DATABASE_URL=your_postgresql_connection_string
JWT_SECRET=your_secure_jwt_secret
```

Start the development server:

```bash
npm run dev
```
